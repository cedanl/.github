# CEDA Ontwikkelaarshandboek

Welkom bij de technische documentatie van het [Centrum Educatieve Data Analyse (CEDA)](https://github.com/cedanl). Hier leggen wij vast hoe we samen met mbo, hbo en wo open source pakketten bouwen in Python en R — uitvoerbaar op je eigen machine, met je eigen data.

## Voor ontwikkelaars bij instellingen en co-creators

Werk je als data-analist, onderzoeker of ontwikkelaar bij een onderwijsinstelling? Deze onderdelen helpen je om CEDA-code te begrijpen, lokaal te draaien en mee te verbeteren.

| Onderdeel | Wat vind je hier? |
| :--- | :--- |
| **[Ontwikkelstandaarden](standards/index.md)** | Twaalf ontwikkelprincipes, vaste pakketstructuur, dataconventies en stijlgidsen voor [Python](standards/python-style.md) en [R](standards/r-style.md). |
| **[Ontwikkelstack en tooling](tooling/index.md)** | Met welke talen, pakketbeheerders, bestandsformaten en containers wij werken en waarom. |
| **[Meebouwen en bijdragen](bijdragen/index.md)** | Hoe je veilig een fout meldt, test met synthetische demodata, een pull request opent of een eigen oplossing inbrengt. |
